# Target Frenzy
<b> Duration: January - October 2026 </b> <br>

<h2> About Target Frenzy </h2>

Target Frenzy is a short light-gun shooter inspired by Duck Hunt and other classic light gun games. You can read the GDD <a href="https://amroelsheikh123.wixsite.com/portfolio/target-frenzy-project"> here!</a></p>

Target Frenzy features six unique targets, some of which have an impact on gameplay. Furthermore, taking down specific targets increases your counter. Hit ten of them without missing, and you'll enter the bonus round, where you have the chance to boost your score even further!


The goal of this project is to shift focus from large, overscoped projects, to smaller,
more-focused projects. Taking everything I’ve learnt at university and not only directly
applying it to Target Frenzy, but laying the groundwork for a more efficient workflow for
future projects!
